# Fuhao 箱包制造主题 V0.2

面向箱包制造企业的 WordPress 经典主题，适用于国内及海外 B2B 客户了解产品、合作方式、工厂能力并提交询盘。主题不包含商城、购物车、在线价格或库存数量。

- 需要 WordPress 6.0+、PHP 7.4+
- 不依赖插件即可运行（邮件送达建议配合 SMTP 插件）
- 默认文案与联系方式已按确认信息填写，不再是示例占位
- 中英文切换位置已预留，当前仅提供中文内容

## 一、安装与启用

1. 登录 WordPress 后台。
2. 进入「外观 → 主题 → 添加新主题 → 上传主题」。
3. 上传 `fuhao-theme-v0.2.zip`，安装并启用。
4. 首次启用后，主题会自动创建 6 个页面：
   - 现货供应（`/stock/`）
   - 定制服务（`/customization/`）
   - 工厂实力（`/factory/`）
   - 关于我们（`/about/`）
   - 联系我们（`/contact/`）
   - 隐私政策（`/privacy/`）
5. 同时创建 7 个产品分类：折叠双肩包、化妆包收纳、鞋子收纳、棉被衣物收纳、数码收纳、学生书包、多巴胺潮流。
6. 如果页面 404，进入「设置 → 固定链接」，直接点击「保存更改」。

> 已存在同名页面（相同别名）时不会覆盖。页面模板由文件名自动匹配，不需要在后台选择模板。

## 三、添加产品

1. 后台「产品 → 添加产品」。
2. 填写标题、产品介绍（正文）与摘要。
3. 选择「产品分类」；可选填「用途标签」。
4. 在右侧「供货类型」选择：**现货、现货定制、批量定制**。该字段只表示合作方式，不表示库存数量。
5. 设置「特色图片」作为封面；未设置时显示内置占位图。
6. 发布后，产品会出现在产品中心与对应分类页。

产品详情页包含分类标签、供货类型与询价按钮，不显示价格、库存、起订量或固定交期。

## 四、页面说明

以下页面使用主题内置模板，版式与文案已按确认内容固定：

- **现货供应**：服务内容、下单前确认事项、合作流程；不公开库存数量。
- **定制服务**：现货定制、批量定制、OEM / ODM；定制范围与流程；起订量、打样费与交期按项目评估。
- **工厂实力**：公司与工厂分别表述；26+ 年、6 个厂区、300+ 员工、3–5 万日产能；生产与品控。

- **联系我们**：3 位联系人、WhatsApp、3 个邮箱、地址与询盘表单。
- **隐私政策**：说明询盘信息的收集、使用、保存与联系渠道。

这些页面的正文编辑器内容不会显示；如需调整固定文案，请修改对应 `page-*.php` 文件。

## 五、导航菜单

主题启用后无需配置菜单，默认显示：

首页｜产品中心｜现货供应｜定制服务｜工厂实力｜关于我们｜联系我们

如需自定义：

1. 「外观 → 菜单」新建菜单，添加到「主导航」位置。
2. 内页链接可直接选择已创建的页面；首页锚点可填 `/#products`、`/#about`、`/#process`、`/#oem`、`/#contact`。
3. 可另建「底部导航」菜单，页脚会显示「隐私政策」入口。

## 六、询盘邮件

- 收件人：优先使用「联系方式 → 询盘收件邮箱」，默认 `19884501223@163.com`。
- 抄送：QQ 邮箱与 Gmail 会自动抄送；与主收件人相同的地址不会重复发送。
- 回复：邮件头使用访客填写的邮箱作为 Reply-To。
- 表单包含安全校验、蜜罐字段与隐私政策勾选；未勾选隐私政策不会提交成功。
- WordPress 默认邮件常被服务器限制或判为垃圾邮件，正式使用前建议安装 **WP Mail SMTP** 并配置企业邮箱。
- 提交成功后返回原页面的 `#contact` 并显示提示；失败时提示直接发邮件。

## 七、SEO 与分享

- 自动输出页面描述、Open Graph 与 Twitter 分享标签。
- 自动输出 Organization、WebSite 与产品 Product 结构化数据。
- 搜索结果与 404 页面设置为不收录。
- 产品描述优先取「摘要」，没有摘要时取正文前 150 字。
- 分享图片优先取产品特色图片，其次取首页主视觉背景图，最后取站点图标。建议在「站点身份」上传 512×512 站点图标。
- 上传图片时请填写 ALT 文本，建议描述产品名称、用途或场景，不要堆砌关键词。

## 八、图片说明

主题不内置产品与工厂照片，使用线性图标与几何占位，避免版权问题：

- 首页 Banner：「外观 → 自定义 → 首页主视觉 → 背景图片」。
- 工厂照片：「工厂实力 → 工厂照片」。
- 产品图：为每个产品设置「特色图片」，建议横版 4:3、1200px 以上。
- 产品分类与行业图标为主题内置 SVG，无需上传。

## 十、常见问题

- **页面 404**：进入「设置 → 固定链接」，点击「保存更改」刷新链接。
- **收不到询盘邮件**：先检查垃圾邮件，再安装 WP Mail SMTP 并配置企业邮箱。
- **首页没有产品**：产品中心首页显示的是产品分类，不显示单个产品；点击分类即可查看产品。
- **想换 Logo**：「外观 → 自定义 → 站点身份」上传 Logo；不上传时显示品牌文字标。
- **修改固定页面文案**：现货、定制、工厂、关于、联系、隐私页面的文案在 `page-*.php` 中，修改前建议先备份。
- **ICP 备案号**：在「页脚信息 → ICP 备案号」填写后才会显示。

## 十一、上线前需要确认

- 公司成立时间（2026 年）与工厂制造经验（26+ 年）必须分别表述，不能合并成「公司成立 26 年」。
- 公开信息中不使用未确认的厂房面积、设备数量、客户名称或客户 Logo。
- 网站不公开注册资本、法定代表人、注册地址与营业执照编号；营业执照图片不公开展示。
- 如公开「300+ 员工」「3–5 万日产能」「6 个厂区」，请确认这些数字可以对外发布。
- 如工厂为合作工厂，请确认官网表述为「生产工厂」还是「合作工厂」。
- 隐私政策为通用模板，正式上线前请按实际数据处理方式与邮件服务商情况核对。
- 正式上线前请在测试站验证询盘邮件送达、移动端导航与表单提交。

- 仅中文内容，英文版需后续补充。
